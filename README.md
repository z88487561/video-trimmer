# 本機影片裁切與編輯 PWA

在瀏覽器中以 FFmpeg WASM 本機裁切影片，不會上傳。預設以 stream copy 模式裁掉片頭／片尾，不重新編碼；也可選擇移除音訊、順時針旋轉、裁成常見比例，或指定解析度與品質壓縮影片。第一次處理會從 jsDelivr 下載並在瀏覽器快取 FFmpeg 核心（約 32 MB）；快取完成後可離線使用。

## 無損裁切限制

`-c copy` 只複製既有影音封包，不會逐影格重新編碼。開始點可能需落在前一個關鍵影格，結束點及音訊也會受封包邊界影響，因此不能承諾精確到指定影格／毫秒。要求精準裁切時必須重新編碼。輸出維持來源副檔名，實際可處理容器與軌道依 FFmpeg WASM 核心支援而異。無損裁切不會額外將 MP4 索引移至檔案開頭，以避免對整個輸出再做一次搬移；輸入以瀏覽器 WorkerFS 掛載，避免先把整個來源檔複製進記憶體；輸出檔仍需暫存在瀏覽器記憶體，超大型輸出受裝置可用記憶體限制。

在影片進度條下方的雙把手時間軸或秒數欄位設定起訖點。選擇移除音訊、旋轉、畫面比例或壓縮後可能需要重新編碼，轉換輸出為 MP4；自訂比例的裁切框可在預覽畫面中拖曳定位。轉碼時 FFmpeg 會先快速定位至所選片段，再直接套用濾鏡及編碼，避免建立額外的中間檔。壓縮解析度提供自動、720p、480p，只會縮小：自動將高於 720p 的影片縮至 720p、介於 480p 與 720p 的影片縮至 480p；480p 以下或相同的來源不會縮放。手動解析度只允許選擇低於來源的目標。重新編碼的速度與實際檔案大小會依裝置、來源影片和內容而異。

## 執行核心與授權

FFmpeg WASM JavaScript client（`vendor/ffmpeg/`）採 MIT 授權。FFmpeg 核心不隨此工作區散佈；首次執行時從 `@ffmpeg/core@0.12.10` jsDelivr CDN 載入並快取到瀏覽器。該 FFmpeg 核心採 GPL-2.0-or-later，使用／重新散佈前請依其授權條款辦理。核心版本固定，影片檔案不會送至 CDN。
